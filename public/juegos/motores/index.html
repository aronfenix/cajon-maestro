Motores

Los juegos de recta, cifras y rejilla no tienen código propio. Cada uno es una carpeta con un index.html que solo lleva sus datos. Para hacer uno nuevo se copia una carpeta y se cambian los datos.

Cómo hacer un juego nuevo

  1. Copia la carpeta del juego más parecido (por ejemplo public/juegos/picos-en-la-recta) y ponle otro nombre, sin espacios ni tildes: rios-en-la-recta.
  2. Abre su index.html. Solo hay que tocar el bloque <script type="application/json" id="config">: título, subtítulo, área, la pregunta final y las rondas.
  3. Si algo está mal escrito, el juego no se rompe en silencio: dice qué falla en la pantalla.
  4. Sube una ficha de tipo «juego» con el enlace /juegos/rios-en-la-recta/.

Campos comunes a todos: motor (recta, cifras o rejilla), titulo, subtitulo, area (lengua, matematicas, naturales, sociales, plastica, valores: cambia el color), volver (enlace a su ficha), observa (la pregunta de la pantalla final) y rondas.

En cada ronda: texto cambia el enunciado (lo que va entre ** sale resaltado), pista la línea de ayuda, explica lo que se añade al comprobar, repetir cuántas veces sale y generar hace que los números salgan al azar en cada partida.

Todos tienen modo Pizarra (sin puntos, para proyectar). Para abrir un juego directamente así, añade ?pizarra al final del enlace.

Recta

Tres modos. estimar: clavar un valor en una recta que solo tiene algunos números. ordenar: colgar varias tarjetas en su sitio (ordenar y estimar a la vez). saltos: ir de un número a otro con el menor número de saltos; el juego calcula el camino más corto y lo enseña.

{ "modo": "ordenar", "min": 0, "max": 1100, "marcas": [0, 500, 1000], "unidad": "km",
  "texto": "Cuelga cada río **por su longitud**",
  "tarjetas": [ { "texto": "Tajo", "valor": 1007 }, { "texto": "Ebro", "valor": 930 } ] }

{ "modo": "estimar", "min": 1400, "max": 2000, "marcas": [1400, 1500, 1600, 1700, 1800, 1900, 2000],
  "valor": 1492, "etiqueta": "Colón llega a América" }

{ "modo": "saltos", "inicio": 37, "meta": 100, "saltos": [1, 10], "restar": true }
{ "modo": "estimar", "generar": { "redondeo": 10 }, "min": 0, "max": 10000, "marcas": [0, 10000] }
  • Otros campos: divisiones (rayitas sin número), decimales, tolerancia (porcentajes para 3, 2 y 1 estrella; por defecto 2, 5 y 10), mostrarValor (false para que las tarjetas no enseñen su número hasta comprobar).
  • Ideas: fechas de Historia, altitudes y longitudes, temperaturas bajo cero, fracciones y decimales entre 0 y 1, etapas de la vida de un ser vivo.

Cifras

Una máquina con huecos (con su nombre: UM, C, D, U, d, c…) y un montón de cifras. El juego prueba todas las colocaciones posibles, así que sabe cuál era la mejor y en qué puesto ha quedado la del alumno.

{ "huecos": 4, "cifras": [3, 0, 8, 5], "objetivo": "min" }
{ "huecos": 4, "generar": true, "objetivo": "max", "condicion": "par" }
{ "huecos": 3, "decimales": 1, "cifras": [4, 9, 2, 7], "objetivo": "cerca", "valor": 50 }
{ "huecos": 5, "generar": { "cantidad": 5, "cerca": [40000, 60000] }, "objetivo": "cerca", "aCiegas": true }
  • objetivo: max, min o cerca (con valor). condicion: par, impar o multiplo:5 (o del número que sea).
  • aCiegas: las cifras salen de una en una y no se pueden mover. Es la ronda con más estrategia: ¿dónde pongo un 5 si no sé qué viene después?
  • Si hay más cifras que huecos, sobran: el juego lo avisa.

Rejilla

Una cuadrícula de casillas y una regla: hay que pintar las que la cumplen. Se pinta tocando o arrastrando el dedo. Al comprobar se ven las que faltaban y las que sobraban. Con mantener, lo bueno de las rondas anteriores se queda rayado: sirve para ver coincidencias (múltiplos de 2 y de 3) o para clasificar por descarte.

{ "desde": 1, "hasta": 100, "regla": { "multiplo": 3 }, "texto": "Pinta los **múltiplos de 3**" }
{ "desde": 1, "hasta": 50, "regla": { "primo": true } }
{ "items": ["león", "pino", "seta", "trucha"], "columnas": 4, "regla": { "lista": ["león", "trucha"] },
  "texto": "Pinta los **animales vertebrados**" }
{ "items": [ { "t": "célula", "si": true }, { "t": "roca", "si": false } ], "columnas": 2 }
  • Reglas para números: multiplo, divisor, cuadrado, primo, acabaEn. Para palabras: lista con las que van, o "si": true en cada una.
  • Campos: columnas, mantener, textoAntes (la leyenda de las rayadas).
  • Ideas: seres vivos e inertes, sustantivos de un texto, palabras con b o con v, provincias de una comunidad, materiales que conducen la electricidad.
